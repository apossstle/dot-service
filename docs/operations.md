# Топологические операции

Сервис умеет объединять, пересекать, вычитать полигоны и строить буфер вокруг них. Вычисления выполняет библиотека [shapely](https://shapely.readthedocs.io/) (обёртка над GEOS), код — `geometry/ops.py`, эндпоинты — `api/server.py`.

Операции работают только над уже сохранёнными полигонами текущего пользователя и **ничего не сохраняют**: результат возвращается в ответе, исходные полигоны не меняются.

## Общий формат

```
POST /operations/{union|intersection|difference|buffer}
Content-Type: application/json
X-User-Id: <id пользователя>
```

Тело запроса:

| Поле | Тип | Где нужно | Описание |
|---|---|---|---|
| `polygon_ids` | список строк | везде | id полигонов, порядок важен для `difference` |
| `distance` | число | только `buffer` | расстояние в единицах координат (для WGS84 — градусы) |

Ответ `200 OK`:

```json
{
  "operation": "intersection",
  "polygon_ids": ["<id A>", "<id B>"],
  "geometry": { "type": "Polygon", "coordinates": [...] },
  "wkt": "POLYGON ((...))"
}
```

- `geometry` — GeoJSON `Polygon` или `MultiPolygon`. Если результат распался на несколько частей, придёт `MultiPolygon`.
- Если у результата нет площади (полигоны не пересекаются, касаются только ребром или углом, буфер схлопнулся), то `geometry` и `wkt` равны `null`. Это не ошибка, статус всё равно `200`.

## Подготовка: два полигона для примеров

```bash
curl -s -X POST http://127.0.0.1:8080/polygons \
  -H "Content-Type: application/json" -H "X-User-Id: demo" \
  -d '{"name": "A", "wkt": "POLYGON((0 0, 2 0, 2 2, 0 2, 0 0))"}'

curl -s -X POST http://127.0.0.1:8080/polygons \
  -H "Content-Type: application/json" -H "X-User-Id: demo" \
  -d '{"name": "B", "wkt": "POLYGON((1 1, 3 1, 3 3, 1 3, 1 1))"}'
```

Из ответов взять поле `id` и подставить ниже вместо `<id A>` и `<id B>`. Квадраты A и B 2×2 перекрываются в квадрате 1×1.

## union — объединение

Нужно минимум 2 полигона. Возвращает общую площадь всех полигонов.

```bash
curl -s -X POST http://127.0.0.1:8080/operations/union \
  -H "Content-Type: application/json" -H "X-User-Id: demo" \
  -d '{"polygon_ids": ["<id A>", "<id B>"]}'
```

```json
{
  "operation": "union",
  "polygon_ids": ["<id A>", "<id B>"],
  "geometry": {"type": "Polygon", "coordinates": [[[2.0, 0.0], [0.0, 0.0], [0.0, 2.0], [1.0, 2.0], [1.0, 3.0], [3.0, 3.0], [3.0, 1.0], [2.0, 1.0], [2.0, 0.0]]]},
  "wkt": "POLYGON ((2.0 0.0, 0.0 0.0, 0.0 2.0, 1.0 2.0, 1.0 3.0, 3.0 3.0, 3.0 1.0, 2.0 1.0, 2.0 0.0))"
}
```

Площадь результата 7 = 4 + 4 − 1. Если объединить непересекающиеся полигоны, придёт `MultiPolygon`:

```
MULTIPOLYGON (((0.0 2.0, 2.0 2.0, 2.0 0.0, 0.0 0.0, 0.0 2.0)), ((10.0 11.0, 11.0 11.0, 11.0 10.0, 10.0 10.0, 10.0 11.0)))
```

## intersection — пересечение

Нужно минимум 2 полигона. Возвращает область, которая входит во **все** переданные полигоны.

```bash
curl -s -X POST http://127.0.0.1:8080/operations/intersection \
  -H "Content-Type: application/json" -H "X-User-Id: demo" \
  -d '{"polygon_ids": ["<id A>", "<id B>"]}'
```

```json
{
  "operation": "intersection",
  "polygon_ids": ["<id A>", "<id B>"],
  "geometry": {"type": "Polygon", "coordinates": [[[2.0, 2.0], [2.0, 1.0], [1.0, 1.0], [1.0, 2.0], [2.0, 2.0]]]},
  "wkt": "POLYGON ((2.0 2.0, 2.0 1.0, 1.0 1.0, 1.0 2.0, 2.0 2.0))"
}
```

Если полигоны не пересекаются:

```json
{"operation": "intersection", "polygon_ids": ["<id A>", "<id C>"], "geometry": null, "wkt": null}
```

## difference — разность

Нужно минимум 2 полигона. **Первый id — из чего вычитаем**, все остальные вычитаются из него. Порядок важен: `A − B` и `B − A` дают разные результаты.

```bash
curl -s -X POST http://127.0.0.1:8080/operations/difference \
  -H "Content-Type: application/json" -H "X-User-Id: demo" \
  -d '{"polygon_ids": ["<id A>", "<id B>"]}'
```

```json
{
  "operation": "difference",
  "polygon_ids": ["<id A>", "<id B>"],
  "geometry": {"type": "Polygon", "coordinates": [[[2.0, 0.0], [0.0, 0.0], [0.0, 2.0], [1.0, 2.0], [1.0, 1.0], [2.0, 1.0], [2.0, 0.0]]]},
  "wkt": "POLYGON ((2.0 0.0, 0.0 0.0, 0.0 2.0, 1.0 2.0, 1.0 1.0, 2.0 1.0, 2.0 0.0))"
}
```

Результат — квадрат A без угла площадью 1. Если вычитаемый полигон лежит целиком внутри первого, в результате появится отверстие. Если вычитаемый полностью накрывает первый, придёт `null`.

## buffer — буфер

Нужен **ровно один** полигон и поле `distance`.

- `distance > 0` — полигон расширяется, углы скругляются.
- `distance < 0` — полигон сужается. Если сузить сильнее половины ширины, он исчезает, придёт `null`.
- `distance = 0` — исправляет невалидную геометрию, площадь не меняется.

```bash
curl -s -X POST http://127.0.0.1:8080/operations/buffer \
  -H "Content-Type: application/json" -H "X-User-Id: demo" \
  -d '{"polygon_ids": ["<id A>"], "distance": 0.5}'
```

В ответе будет `Polygon` со скруглёнными углами (69 точек), bounding box расширится до `(-0.5, -0.5, 2.5, 2.5)`:

```
POLYGON ((-0.5 0.0, -0.5 2.0, -0.4975923633360984 2.0490085701647804, ...))
```

Для координат WGS84 `distance` задаётся в градусах: 0.01° по широте ≈ 1.1 км, по долготе в Москве ≈ 0.63 км. Буфер в метрах пока не поддерживается.

## Ошибки

| Ситуация | Статус | Тело ответа |
|---|---|---|
| Нет заголовка `X-User-Id` | 400 | `{"error": "Заголовок 'X-User-Id' обязателен"}` |
| Нет `polygon_ids`, пустой список или не строки | 400 | `{"error": "Поле 'polygon_ids' обязательно: список id полигонов"}` |
| `union` / `intersection` с одним полигоном | 400 | `{"error": "Для union нужно минимум 2 геометрии"}` |
| `difference` с одним полигоном | 400 | `{"error": "Для difference нужно минимум 2 геометрии"}` |
| `buffer` без `distance` или с нечисловым значением | 400 | `{"error": "distance должен быть конечным числом"}` |
| `buffer` с несколькими полигонами | 400 | `{"error": "Для buffer нужен ровно один полигон"}` |
| Полигон не найден или принадлежит другому пользователю | 404 | `{"error": "Полигон '<id>' не найден"}` |
| Неизвестная операция, например `/operations/xor` | 404 | `{"error": "Маршрут не найден: POST /operations/xor"}` |

## Невалидные полигоны

Перед операцией каждая геометрия проверяется. Самопересекающиеся полигоны (например, «бантик» `POLYGON((0 0, 2 2, 2 0, 0 2, 0 0))`) исправляются через `shapely.make_valid` и дальше участвуют в операции как набор корректных частей.
