## Приоритизация на случай задержек (MoSCoW)

**MUST (критично для защиты)**
- Аналитические документы (SWOT, риски, user stories, нефункциональные требования)
- R-Tree интеграция + бенчмарк
- Топологические операции (минимум union + intersection)
- Хоть одна форма персистентного хранилища (можно начать с SQLite вместо PostgreSQL)
- Отчёт о бенчмарках

**SHOULD (сильно украшает проект)**
- Полная поддержка PostgreSQL + PostGIS
- Пакетный импорт из GeoJSON
- Docker-композиция

**COULD (приятный бонус)**
- Импорт из OSM Overpass
- Миграция на FastAPI
- Операция buffer и difference (сверх union+intersection)

**WON'T (вне скоупа этого семестра)**
- Авторизация с паролями (сейчас cookie-ID — этого достаточно для диплома)
- Поддержка WKB (бинарного формата)
- Поддержка CRS, кроме WGS84
- Собственная реализация shapely-операций с нуля
