# Polygon Service

Сервис для хранения полигонов и проверки, попадает ли точка в геометрию.
REST API и веб-карта на OpenStreetMap: полигоны рисуются на карте, точка проверяется кликом.

- Polygon с отверстиями и MultiPolygon, форматы GeoJSON и WKT
- Два алгоритма point-in-polygon: ray casting и winding number
- Три состояния точки: внутри, снаружи, на границе
- Два пространственных индекса: равномерная сетка и R-Tree
- У каждого пользователя свой набор полигонов

## Запуск

Нужен Python 3.10+.

```bash
pip install rtree
python main.py
```

Откройте http://127.0.0.1:8080. На macOS и Linux вместо `python` обычно `python3`, на Windows — `py -3`, если `python` не находится.

| Флаг | Переменная | По умолчанию | |
|---|---|---|---|
| `--port` | `PORT` | `8080` | порт |
| `--index` | `INDEX_TYPE` | `grid` | индекс: `grid` или `rtree` |
| `--cell-size` | `CELL_SIZE` | `1.0` | размер ячейки сетки, в единицах координат |

Сервис слушает только `127.0.0.1`. Для координат lng/lat шаг `1.0` — это градус, для города лучше `0.02`–`0.05`:

```bash
python main.py --index grid --cell-size 0.02
```

## API

Полигоны привязаны к пользователю. Его идентификатор передаётся заголовком `X-User-Id` или cookie `ps_uid`. Веб-интерфейс получает cookie сам при первом создании полигона. Без идентификатора чтение и проверка точки вернут `400`.

| Метод | Путь | |
|---|---|---|
| `GET` | `/` | веб-интерфейс |
| `GET` | `/health` | статус сервиса |
| `GET` | `/stats` | статистика индекса |
| `GET` | `/polygons` | полигоны пользователя |
| `POST` | `/polygons` | создать |
| `GET` `PUT` `DELETE` | `/polygons/{id}` | получить, изменить, удалить |
| `POST` | `/query/point-in-polygon` | найти полигоны, содержащие точку |

Ошибки приходят как `{"error": "..."}` с кодом `400`, `404` или `500`.

### Создать полигон

Геометрию можно передать в GeoJSON или WKT:

```http
POST /polygons
X-User-Id: demo
Content-Type: application/json

{
  "name": "Зона А",
  "wkt": "POLYGON ((37.6 55.7, 37.7 55.7, 37.7 55.8, 37.6 55.8, 37.6 55.7))",
  "properties": {"region": "Moscow"}
}
```

```json
{
  "name": "Зона А",
  "geometry": {
    "type": "Polygon",
    "coordinates": [[[37.6, 55.7], [37.7, 55.7], [37.7, 55.8], [37.6, 55.8], [37.6, 55.7]]]
  }
}
```

Первое кольцо — внешний контур, следующие — отверстия. В ответе полигон приходит сразу в обоих форматах.

### Проверить точку

```http
POST /query/point-in-polygon
X-User-Id: demo
Content-Type: application/json

{"point": [37.65, 55.75], "algorithm": "ray_casting", "include_boundary": true}
```

| Поле | |
|---|---|
| `point` | `[x, y]` или `[lng, lat]`, обязательно |
| `algorithm` | `ray_casting` (по умолчанию) или `winding_number` |
| `include_boundary` | считать ли точку на границе попаданием, по умолчанию `true` |

В ответе — все полигоны, которые содержат точку.

## Как это работает

**Ray casting** — из точки проводится луч вправо и считаются пересечения с рёбрами: нечётное число — внутри.
**Winding number** — считается, сколько раз контур обходит точку: не ноль — внутри. Устойчивее к самопересечениям.
Оба работают за O(n) на кольцо. Перед ними точка проверяется на попадание на ребро с допуском `1e-10`.

| Случай | Результат |
|---|---|
| точка на ребре или в вершине | `on_boundary` |
| точка внутри отверстия | `outside` |
| точка на границе отверстия | `on_boundary` |
| точка в нескольких полигонах | возвращаются все |

Чтобы не проверять точку против всех полигонов, индекс сначала отбирает кандидатов по ограничивающим прямоугольникам:

- **`grid`** — равномерная сетка, поиск ячейки за O(1). Быстрее на запросах, но зависит от `--cell-size`: при неудачном шаге резко растут время построения и память.
- **`rtree`** — R-Tree на `libspatialindex`, O(log n). Не требует настройки и экономнее по памяти, когда полигоны сильно различаются по размеру.

Замеры на синтетике и районах Москвы — в [docs/benchmarks.md](docs/benchmarks.md).

## Ограничения

- Данные хранятся в памяти и пропадают после перезапуска.
- Только Polygon и MultiPolygon; WKB не поддерживается.
- Однопоточный `HTTPServer`.
- Пользователь определяется по `X-User-Id` или cookie без паролей — это разделение данных, а не защита.
